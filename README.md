# Prediction-Powered Adaptive Evaluation (aPPE)

Code for the paper *Prediction-Powered Adaptive Evaluation of AI-based Wireless Systems*.

aPPE evaluates the performance K\* of a test model, i.e., its success rate on a benchmark of N samples, without running the model on every sample. A factor model fitted on the outcomes of historical models predicts the outcome of the test model on each sample. These predictions guide the choice of the next sample and enter a prediction-powered estimate. Betting-based e-processes, mixed over several reliance levels on the predictions, give a confidence sequence that is valid at every round. Hence, the evaluation can stop as soon as the interval is narrower than a target width W_th. The fixed-budget PPE method and uniform sampling are included as baselines.

## Installation

```bash
pip install -r requirements.txt
```

The code was tested with Python 3.10 and PyTorch 2.5.1 (CUDA 12.1). A GPU is recommended, since every setting is repeated over 200 runs. The channel-estimation experiments also require [Sionna Bench](https://github.com/NVlabs/sionna-bench) (commit `e1d2fdb`), installed as described in its repository.

## Data

- **RadioML 2018.01A:** download `GOLD_XYZ_OSC.0001_1024.hdf5` from [DeepSig](https://www.deepsig.ai/datasets/).
- **DeepSense 6G:** download scenarios 1–9 from [DeepSense 6G](https://www.deepsense6g.net/). The zip files can be read without extraction.
- **Sionna Bench:** the slots are generated by the link-level simulation of the benchmark, so no download is needed.
- **RAN emulation:** the benchmark is built from runs of the real-time emulator [MAC-Gyver](https://github.com/wineslab/MAC-Gyver).

## Usage

All tasks share the same pipeline: (1) build the benchmark D; (2) evaluate a zoo of models on all samples of D to obtain their success vectors; (3) assemble H and hold out the test models; (4) fit the factor model; (5) run PPE, aPPE, and the baselines; (6) summarize the results.

**Modulation classification.**

```bash
python radioml_data.py --h5 data/raw/GOLD_XYZ_OSC.0001_1024.hdf5 --out data/radioml2018
bash run_train_zoo.sh data/radioml2018 outputs/zoo 0,1,2,3
python build_history.py --zoo outputs/zoo --out outputs/history.npz --holdout random --n_candidates 12
python factor_model.py --history outputs/history.npz --out outputs/factor.npz --cv
bash run_experiments.sh 0,1,2,3
python analyze_results.py --results results --out figures
```

`run_train_zoo.sh` starts one worker per GPU, and `run_experiments.sh` queues its jobs over the given GPUs. Both skip finished work, so that an interrupted job is resumed by starting it again. The input and output paths, and the test models whose interval paths are saved, are set by the environment variables `HISTORY`, `FACTOR`, `RESULTS`, `LOGS`, `PATH_CANDS`, and `PATH_TBAR` of `run_experiments.sh`.

**Beam prediction.**

```bash
python deepsense_data.py --root data/raw_deepsense --scenarios 1 2 3 4 5 6 7 8 9 --out data/deepsense
python train_zoo_ds.py --download_weights
SCRIPT=train_zoo_ds.py bash run_train_zoo.sh data/deepsense outputs_ds/zoo 0,1,2,3
python build_history.py --zoo outputs_ds/zoo --out outputs_ds/history.npz --key db1 --holdout random --n_candidates 12
python factor_model.py --history outputs_ds/history.npz --out outputs_ds/factor.npz --cv
HISTORY=outputs_ds/history.npz FACTOR=outputs_ds/factor.npz RESULTS=results_ds LOGS=logs_ds \
  PATH_CANDS=032_vision_resnet18_r144_f1_s2 PATH_TBAR=4000 bash run_experiments.sh 0,1,2,3
python analyze_results.py --results results_ds --out figures_ds
```

**Channel estimation.** The zoo is first evaluated on 250 batches of 4 slots at all Eb/N0 values of the benchmark, and is then extended to 460 batches at the retained values Eb/N0 ≥ 2.5 dB. `sb_check.py` compares the first 63 batches, which coincide with the canonical benchmark, with the published results of Sionna Bench.

```bash
python sb_zoo.py
python sb_check.py
python sb_zoo.py --zoo zoo_sb_ext --work work_sb_ext --batches 460 --first_batch 250 --ebno_min 2.5 --no_prepare
python sb_merge.py --base zoo_sb --ext zoo_sb_ext --ebno_min 2.5 --out zoo_sb460
ZOO=zoo_sb460 TEST=sparse_diffuse OUT=outputs_sb460 RESULTS=results_sb460 LOGS=logs_sb460 bash run_experiments_sb.sh 0
python analyze_results.py --results results_sb460 --out figures_sb460
```

**RAN emulation.** `build_history_nostra.py` reads the emulation runs from `campaign/runs*.jsonl`, with one record per run (`config`, `arm`, `rep`, `valid`, `dl_mbps`, `wall_s`), where `arm` is a predictor or `olla`. It also reads the configurations from `campaign/configs.csv` and the predictors from `models/models.csv` (`name`, `run`, `is_snapshot`).

```bash
bash run_experiments_nostra.sh
python analyze_results.py --results results_nostra/collab --out figures_nostra --paths_tmax 400 --paths_widths 0.2 0.15 0.1
python analyze_nostra.py --results results_nostra --histories outputs_nostra --out figures_nostra
```

## Experimental Settings

### Tasks

| | Modulation classification | Beam prediction | Channel estimation | RAN emulation |
|---|---|---|---|---|
| Benchmark D | RadioML 2018.01A, 32 frames per modulation–SNR pair | DeepSense 6G scenarios 1–9, 50% of the vehicle passes of each scenario | Sionna Bench, 1,840 slots per Eb/N0 = 2.5, 5, ..., 15 dB | Emulated network configurations |
| N | 19,968 | 11,591 | 11,040 | 1,200 |
| Success k_i = 1 | Correct modulation label | Received-power loss ≤ 1 dB relative to the best beam | All codewords of the slot decoded | Downlink cell goodput ≥ 1.01 × that of OLLA alone |
| Historical models | 170 classifiers | 150 beam predictors | 42 channel estimators | 11 predictors |
| Test model | Inception, K\* = 0.575 | Image-only ResNet-18, K\* = 0.96 | Hybrid sparse/diffuse estimator, K\* = 0.782 | Reference predictor, K\* = 0.647 |
| (d, κ) | (16, 10) | (32, 10) | (32, 1) | (3, 10) |

**Modulation classification.** For each modulation–SNR pair, 64 frames are used for validation and 1,024 frames for training, disjoint from each other and from D. The classifiers come from ten architectures: MLP, CNN, VGG, ResNet, dilated residual CNN, Inception, LSTM, CLDNN, bidirectional GRU, and Transformer. Their configurations vary in network width, input length, training-set size, i.e., 10% to 100% of the training data, and random seed.

**Beam prediction.** Within each scenario, 10% and 40% of the vehicle passes are used for validation and training, respectively, disjoint from the passes of D. The neural models comprise eleven image-only CNNs with ImageNet-pretrained backbones, three position-only MLPs, and two image–position fusion networks. Each is trained with three random seeds on 30% to 100% of the training passes or on subsets of the scenarios. Classical classifiers on the position, such as nearest-neighbor methods, random forests, and gradient boosting, complete the zoo.

**Channel estimation.** The link-level simulation is an uplink in which four single-antenna UEs transmit to a base station with 16 antennas over 3GPP urban microcell channels. All estimators use the implementations and training procedures of Sionna Bench, with training data generated independently of D. The 42 historical estimators come from eight methods, namely LS estimation with interpolation, sparse Bayesian learning, LMMSE estimation, delay-domain truncation, Gaussian mixture models, a residual network, fully connected networks, and an untrained deep-prior network. They comprise 17 reference settings and 25 variants that change, e.g., interpolation filters, numbers of iterations or retained delay taps, training seeds, epochs, and training-set sizes. No variant of the test model is used in offline fitting.

**RAN emulation.** Every configuration is a single cell with saturating downlink traffic, described by four factors: the channel model, either one of six TDL models or a 4 × 2 CDL model with one of five profiles and three delay spreads; the UE speed, between 0 and 60 km/h; the path loss, with a cell mean between 98 and 113 dB and UE-specific offsets of up to 6 dB; and the number of UEs, equal to 4, 8, or 16. One evaluation is a real-time emulation run with a 10 s warm-up and a 30 s measurement period, which takes about one minute. The goodput of OLLA alone is averaged over two reference runs per configuration. The cost is measured by the emulation time of the distinct configurations that are evaluated. Each test model is held out from offline fitting together with the other checkpoints of its training run.

### Factor Model

The hyperparameters (d, κ) are selected by holding out 10% of the entries of H at random. Each setting is fitted on the remaining entries by full-batch Adam with learning rate 0.05 and a cosine schedule for 3,000 iterations, and is assessed by its log-loss on the held-out entries (`factor_model.py --cv`). The grid is d ∈ {2, 4, 8, 16, 32} and κ ∈ {0.1, 1, 10}. For RadioML 2018.01A, κ ∈ {30, 100} is also considered when d ∈ {16, 32}. For RAN emulation, the grid is d ∈ {1, 2, 3, 4, 6}, since at most 11 historical models are available.

### Evaluation

| Parameter | Datasets and link-level simulation (Sec. V) | RAN emulation (Sec. VI) | Option |
|---|---|---|---|
| Target error probability δ | 0.05 | 0.05 | `--delta` |
| Sampling schedule β₀, ν, γ | 1, 0.25, 0.25 | 1, 0.25, 0.25 | `--beta0`, `--rho`, `--gamma` |
| PPE: exploration probability τ | 0.05 | 0.05 | `--tau` |
| PPE: fixed budget T̄ | 4,000 rounds | 400 rounds | `--budgets` |
| aPPE: reliance levels ρ_s, equally weighted | 0, 0.25, 0.5, 0.75, 1 | 0, 0.25, 0.5, 0.75, 1 | `--reliance`, `--weights` |
| aPPE: exploration probability τ | 0.5 | 0.5 | `--tau` |
| aPPE: stake fraction η | 0.5 | 0.9 | `--eta` |
| aPPE: error split ε | 0.5 | 0.5 | `--eps` |
| Target widths W_th | 0.1, 0.05, 0.02 | 0.2, 0.15, 0.1 | `--widths` |
| Runs per test model | 200 | 200 | `--trials` |

PPE uses the plug-in variance estimator of Wu, Nair, and Candès (arXiv:2601.20251). Uniform sampling sets τ = 1 and drops the predictions, which gives the sample mean with the classical CLT interval. aPPE with S = 1 and ρ₁ = 1 (`--reliance 1 --weights 1`) assesses the effect of the reliance mixture. All methods sample with replacement, and a repeated draw reuses the stored outcome. aPPE runs for at most N rounds. The endpoints of the aPPE intervals are bracketed on a uniform grid of 4,001 values of K₀ (`--grid`).
